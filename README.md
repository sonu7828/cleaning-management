# Cleaning Service CRM ERP SaaS Application

This project is a modern enterprise-level Cleaning Service CRM ERP SaaS application built using React.js, Tailwind CSS, Shadcn UI, Framer Motion, React Icons, and Recharts. It features a fully responsive layout, smooth animations, and a professional business workflow.

## Features

- **Responsive Design**: The application is designed to work seamlessly on various devices, ensuring a great user experience on desktops, tablets, and mobile devices.
- **Analytics Dashboard**: Visual insights into business performance with interactive charts and revenue statistics.
- **Client Management**: Manage client information and interactions efficiently with dedicated client cards and lead pipelines.
- **Invoice Management**: A comprehensive invoice table with sorting, filtering, and pagination functionalities.
- **Scheduling System**: Visual representation of job assignments and management through a scheduling board.
- **User Profile Management**: Users can view and edit their profile information easily.

## Technologies Used

- **React.js**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Shadcn UI**: A component library for building modern UIs.
- **Framer Motion**: A library for creating animations in React applications.
- **React Icons**: A library for including icons in React applications.
- **Recharts**: A composable charting library built on React components.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cleaning-crm-saas-ui
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```

## Usage

Once the application is running, you can access the following features:

- **Analytics**: View the analytics dashboard to monitor key metrics.
- **CRM**: Manage clients and leads through the CRM section.
- **ERP**: Handle invoices and operations in the ERP section.
- **Profile**: Update your user profile information.
